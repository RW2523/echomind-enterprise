# EchoMind Law — Programme Documents

EchoMind Law builds on the existing EchoMind Enterprise platform, modified in place on a feature branch. This folder is the single source of truth for the programme. **Every working session starts by reading [PROGRESS.md](PROGRESS.md) and [DECISIONS.md](DECISIONS.md).**

| Document | What it is |
|---|---|
| [CODEBASE_AUDIT.md](CODEBASE_AUDIT.md) | Evidence-based audit of the current repo and runtime (paths, routes, schema, security posture, isolation analysis, defects) |
| [FEATURE_MATRIX.md](FEATURE_MATRIX.md) | Every backlog ID (SEC/RAG/LIVE/MEET/DOC/OPT/OPS): status, evidence, changes, risks, tests, slice, acceptance |
| [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) | Target architecture, data model, authorization model, retrieval isolation, API contracts, phased slices with files, tests, rollback and estimates |
| [THREAT_MODEL.md](THREAT_MODEL.md) | Security principles, 23 threats with exposure → mitigation → test, release gate |
| [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) | "Paper & Glass": Liquid Glass adapted for a legal workspace; tokens, components, screens, accessibility, copy |
| [design/prototype.html](design/prototype.html) | Static visual prototype for approving the direction (open in a browser; deep links `#dark`, `#meetings`, `#documents`, `#recording`) |
| [DECISIONS.md](DECISIONS.md) | Engineering decisions (proposed or approved) and policy decisions awaiting counsel |
| [LICENSE_REGISTER.md](LICENSE_REGISTER.md) | Models, proposed dependencies, candidate datasets; nothing is cleared yet |
| [TEST_RESULTS.md](TEST_RESULTS.md) | Executed test runs only, with commit and command |
| [PROGRESS.md](PROGRESS.md) | Tracker, session log, approvals needed, NEXT EXACT ACTION |
