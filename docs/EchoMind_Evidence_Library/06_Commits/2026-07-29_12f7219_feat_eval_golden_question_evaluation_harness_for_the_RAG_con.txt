    feat(eval): golden-question evaluation harness for the RAG + conversation stack
    
    52 golden questions run against the live backend and score routing (small talk
    / refusals / off-corpus must not cite), retrieval (expected docs cited, doc
    precision), answer facts (grouped alternatives, all groups required), forbidden
    strings (hallucination + dropped-topic canaries), and latency.
    
    - eval/run_eval.py     stdlib-only runner; JSON reports; exit code for CI;
                           optional --judge (LLM-as-judge via local ollama)
    - eval/golden/*.jsonl  per-namespace retrieval sets (bank/health/law/meetings/
                           retail/fmr) drafted from ACTUAL corpus chunks with
                           source-verified facts, + conversational routing set
    - eval/README.md       how to run, scoring rules, how to add questions
    
    First runs immediately caught the five retrieval bugs fixed in the previous
    commit. Run after any change to backend/app/rag/, model swaps, or before demos.
