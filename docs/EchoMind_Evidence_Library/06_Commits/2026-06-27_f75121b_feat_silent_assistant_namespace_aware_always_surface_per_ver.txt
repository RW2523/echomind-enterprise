    feat(silent-assistant): namespace-aware + always-surface + per-vertical rule packs (#3)
    
    Upgrade the live transcription analyzer toward a Parakeet-style live assistant:
    - Namespace-scoped: analyze_segment sets the active KB namespace before retrieval (set_active_namespace),
      so a vertical session is checked only against its own KB. Verified: health->health docs, law->law docs,
      zero cross-namespace leak.
    - Always-surface: every paragraph with relevant KB material now yields a 'Relevant' info card (top
      passages + citation) even when nothing is flagged — the LLM already ran per paragraph, so this is
      ZERO extra GPU cost (we just stop discarding the result).
    - Per-vertical rule packs: domain guidance appended to the analysis prompt per namespace
      (health=drug interactions/dosing, law=risky clauses, bank=KYC/AML disclosures, etc.).
    - Frontend: 'Relevant' label + cyan style; Live Transcription sends namespace + analysis_always_surface.
    
    namespace=''/always_surface absent -> prior behavior (backward compatible).
