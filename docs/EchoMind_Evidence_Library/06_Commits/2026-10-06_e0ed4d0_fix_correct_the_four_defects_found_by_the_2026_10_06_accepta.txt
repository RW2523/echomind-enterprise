      revoked_tokens until expiry; decode_token rejects it). The voice
      WebSocket confirms the session with the backend (/api/auth/me) and
      fails closed, so a logged-out token cannot open a voice session.
    - NC-2026-013 upload: only .pdf/.docx/.pptx/.txt/.md, checked by content
      signature; binary data in text files rejected. HTTP 415 with a reason.

      is recognised by rule; the semantic intent classifier is warmed at
      start-up so its first call is not lost to a cold timeout; the Financial
      Advisor prompt no longer asks the model to guess an FMR chapter.
    - NC-2026-015 export gateway: sk-/sk_ keys with segments, pk/rk_live/test
      keys and api_key=… assignments detected; overlapping matches merged
      before redaction so the redacted copy cannot be corrupted.
