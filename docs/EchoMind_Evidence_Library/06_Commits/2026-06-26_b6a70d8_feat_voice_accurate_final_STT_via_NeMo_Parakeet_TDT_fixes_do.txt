    feat(voice): accurate final STT via NeMo Parakeet-TDT (fixes domain-term mishearing)
    
    The streaming Nemotron-0.6B mangled domain terms ('DoD FMR'->'DODFMA', 'B visa'
    ->'Pizza'), so the LLM answered the wrong (mis-heard) question. Route the FINAL
    transcript (what feeds the LLM) through nvidia/parakeet-tdt-0.6b-v2 via NeMo when
    VOICE_USE_PARAKEET=1; live partials stay on the streaming model; auto-fallback to
    streaming on any error. Pre-warm at startup so the first utterance isn't slow.
    Loads offline from baked cache (air-gap safe). Model baked into the image via commit
    (from-scratch build now also fixed via the huggingface-hub pin).
