    Add Document Studio: AI document generation with on-device images + PDF/PPTX export
    
    Document Studio turns a chat / uploaded reference docs / a brief into a polished, templated document exported as PDF and PPTX:
    - Multi-agent pipeline (planner -> parallel section-writers -> assembler) with 18 templates incl. a marketing suite and a single-page flyer layout; topic-grounded writers, refusal/scaffolding/markdown scrubbing, placeholder bans, heading de-dup and empty-section pruning.
    - On-device image generation (SDXL-Turbo via diffusers) with an art-director subagent that decides placement and writes diffusion-safe prompts; offline 'local' synthetic and cloud 'nim'/'comfyui' backends also supported.
    - Professional renderers: reportlab PDF (cover hero, live TOC, themed sections, banded tables, page-fitted flow diagrams, callouts, embedded images) and python-pptx deck (themed 16:9, hanging-indent native bullets, flow chains, image slides, custom-template render-into-pptx).
    - Custom-template upload (pptx/docx/pdf/md/txt); background jobs + polling; export Cache-Control no-store.
    - Frontend Document Studio tab, images-on-by-default toggle, and an app-wide ErrorBoundary that reports client crashes to the backend.
    
    Supporting fixes in this batch: voice/STT CUDA fault auto-recovery (health 503 + in-process watchdog) and a prompt audit across RAG/refine/transcribe.
