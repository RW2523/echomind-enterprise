# EchoMind Evidence Library

Every document referenced by the four Excel registers EM26-19 (review feedback and actions), EM26-20
(functional requirements), EM26-21 (non-functional requirements) and EM26-22 (roadmap), in one folder.
Compiled 2026-10-12. **Public copy** — clients appear as Client A–D and the 2025 originals (which name the 2025 customer) are held in the controlled copy; the index lists them.

Start with `00_INDEX_EchoMind_Evidence_Library.xlsx`: every reference, where it is in this folder, where the
original lives (GitHub URL, 2025 pack path) and what is held elsewhere (sheet ‘Not held’).

| Folder | Contents |
|---|---|
| 01_Review_Records | One record per review (33): DR-2025-01…15, CR-2026-01…09, SR-2026-01, RV-2026-01…08 — review, findings, decision, actions, evidence. Compiled from EM26-19 and the sources; they are not meeting minutes |
| 02_2025_Source_Records | The 2025 originals: review documents DR/SCH/ACC-1.0, three sets of minutes, SOW summary, both 2025 audit reports, lessons log, roadmap, 2025 test, defect and regression records |
| 03_QMS_Documents | Registers, procedures, form, objectives, manual, gap analysis, audit pack (markdown + Word) |
| 04_Approvals_Releases_and_Versions | AR-2026-001…004, release records v1.4.0/v1.4.1, CAPA review, runtime baseline, changelog, version tags |
| 05_Evidence_Pack_Documents | EM26-02d, EM26-16, EM26-17, EM26-18, EM26-19…22 (with client names) |
| 06_Commits | Each cited commit: author, date, full message, files changed, GitHub link (79 commits) |
| 07_Tests_and_Evaluation | 24 golden-suite runs, research harness E1–E10 and the paper, acceptance runs 1–4 with the harness, test cases, scripts |
| 08_Tickets_and_CI_Runs | Cited GitHub issues and CI runs |
| 09_Source_and_Configuration | docker-compose.yml, backend entry point, capabilities, user manual |
